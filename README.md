## 📌 Sobre este Repositorio

Este repositorio contiene la **bóveda completa de Obsidian** utilizada para la documentación técnica y laboratorios prácticos durante el ciclo de **ASIR**.

El objetivo de mantener esta bóveda pública es construir un **cuaderno de trabajo técnico, portátil y estructurado**, aplicando buenas prácticas de documentación en Markdown y control de versiones con Git desde el primer día.

## ⚙️ Metodología de Estudio & Trabajo

* **Procesamiento Activo ("Prompts Activos"):** Uso de la Inteligencia Artificial como tutor socrático para afianzar conceptos, formular analogías y resolver dudas complejas sin delegar la comprensión intelectual.
* **Documentación Técnica:** Creación de hojas de referencia (*cheat sheets*) de comandos para administración de sistemas en Linux y Windows.
* **Estandarización:** Uso de plantillas personalizadas en Obsidian mediante *callouts* e índices por asignatura.
